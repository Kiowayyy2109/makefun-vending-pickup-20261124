## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

This writes the line to `./output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Python 3 standard library only, no network, deterministic.
